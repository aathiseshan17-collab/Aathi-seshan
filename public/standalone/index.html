🎓 College Project Review & Viva Guide

Academic Presentation Sheet • Student Deadline Companion

1️⃣ Empathize

Observation: College students juggle 5-7 parallel theory and laboratory courses. Deadline announcements are scattered across unorganized WhatsApp groups, multiple Google Classroom feeds, teacher emails, Moodle LMS forums, and handwritten lecture notes.

Pain Points: Cognitive overload, last-minute panic, missed submissions due to buried WhatsApp group messages, inability to tell which assignment is due today vs next week.

2️⃣ Define

Problem Statement: "Undergraduate students need a centralized, lightweight, zero-login deadline companion to organize coursework across fragmented communication channels, enabling instant priority assessment and proactive deadline management."

3️⃣ Ideate

Brainstormed solutions and filtered down to high-impact requirements:

  • Instant visual triage (Overdue alerts, Due Today counter, Next 7 Days lookahead).
  • Source-tagging (WhatsApp, Classroom, Notebook) so students recall where instructions live.
  • Zero friction client-side persistence with browser localStorage (no server latency or signup barriers).
  • Multi-level filtering by Subject, Priority (High/Medium/Low), and keyword search.

4️⃣ Prototype

Implemented a responsive single-page architecture using clean HTML5 semantic structure, modern CSS (Custom Properties, Flexbox, Grid), and modular vanilla JavaScript (ES6+), offering real-time form validation, progress visualization, and quick date chips.

5️⃣ Validate

Tested with realistic university coursework scenarios across mobile and desktop viewport sizes. Verified that students can record a deadline in under 10 seconds and instantly identify urgent deliverables.

Problem Background

In modern higher education, academic communication is split across disparate platforms:

  • Informal announcements in student WhatsApp groups get buried under hundreds of chat messages.
  • LMS portals (Moodle, Blackboard) often require multiple clicks and VPNs to check deadlines.
  • Verbal reminders in classroom lectures are written on loose sheets of paper and easily forgotten.

Project Objectives

  • Centralization: Provide a single dashboard where assignments from all platforms coexist.
  • Prioritization: Highlight urgent items through High/Medium/Low color badges and dynamic time remaining.
  • Accessibility: Ensure instant loading on mobile devices without mandatory server accounts or logins.
  • Reliability: Maintain persistent offline storage via browser localStorage API.

Technology Stack

  • HTML5: Semantic elements (<header>, <main>, <section>, <article>, <datalist>) for accessibility and clean DOM structure.
  • CSS3: CSS Custom Properties (Variables), CSS Grid for stats and forms, Flexbox for responsive navigation, and mobile media queries.
  • Vanilla JavaScript (ES6+): Pure DOM manipulation, modular event handling, array filtering/sorting algorithms, and input validation without heavy framework dependencies.
  • Storage: HTML5 Web Storage API (localStorage) with JSON serialization and backup export/import.

Recommended 2-Minute Reviewer Presentation Flow

  1. Introduction (30s): "Good morning professors. I have developed 'Student Deadline Companion' to solve the widespread student issue of missed deadlines caused by scattered announcements across WhatsApp, Google Classroom, and LMS portals."
  2. Dashboard & Metrics (30s): Point to the 5 top summary cards (Total, Today, This Week, Overdue, Completed) and the completion progress bar. Demonstrate clicking the "Due Today" or "This Week" card to filter instantly.
  3. Adding with Validation (30s): Click + Add Assignment, demonstrate the "Tomorrow" or "+3 Days" shortcut chip, select "WhatsApp" as source, and save with live validation.
  4. Filtering & Persistence (30s): Demonstrate search, filter by High Priority, and mark an assignment completed. Refresh the browser to prove zero data loss via localStorage.
